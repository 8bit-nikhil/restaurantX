# 🍽️ RestaurantX
https://8bit-nikhil.github.io/restaurantX/

### A Modern Restaurant Website

RestaurantX is a modern and visually appealing restaurant website designed to deliver an engaging online dining experience. It features an elegant interface, delicious food visuals, and a user-friendly layout to help visitors explore the restaurant and its offerings.

---

## ✨ Features

- 🎨 **Modern UI** — Clean and attractive website design.
- 📱 **Responsive Design** — Designed to work across desktop, tablet, and mobile screens.
- 🍔 **Food Menu** — Showcase delicious dishes and restaurant specialties.
- 🏠 **Restaurant Overview** — Introduce the restaurant and its dining experience.
- 📞 **Contact Section** — Provide essential restaurant contact information.
- ⚡ **Smooth User Experience** — Simple navigation and an organized layout.

---

## 🛠️ Technologies Used

- **HTML5** — Website structure.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Interactive elements and functionality.

## 🚀 Getting Started

Follow these steps to run RestaurantX locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd RestaurantX
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
